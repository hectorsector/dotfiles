# macOS Window Tiling Shortcuts

Native window tiling shortcuts (macOS Sonoma 14+). Modifier is **fn + Control (^)**.

| Action | Shortcut |
|---|---|
| Move window to left half | `fn + ^ + ←` |
| Move window to right half | `fn + ^ + →` |
| Fill screen (full size) | `fn + ^ + Enter/Return` (or `F`) |
| Move to top half | `fn + ^ + ↑` |
| Move to bottom half | `fn + ^ + ↓` |
| Top-left quarter | `fn + ^ + ←` then `↑` |
| Bottom-right quarter | `fn + ^ + →` then `↓` |
| Center window | `fn + ^ + C` |
| Return to previous size | `fn + ^ + Enter` again |

**Note:** Also accessible via the **Window** menu in any app, or by hovering over the green maximize button (top-left dot) for a tiling menu.
